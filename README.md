# Ability Chess — сборки

3D-шахматы со способностями. Здесь лежат только готовые сборки игры и файл версии для автообновления.

**Первый раз:** открой [последний релиз](https://github.com/Semyon-12/AbilityChess-releases/releases/latest) и скачай архив для своей системы:
- `AbilityChess-macOS-….zip` — распакуй и перетащи `AbilityChess.app` в «Программы» (или любую папку), запускай оттуда.
  Если macOS ругается при первом запуске: правый клик → «Открыть».
- `AbilityChess-Windows-….zip` — распакуй в свою папку (например, на рабочий стол) и запусти `AbilityChess.exe`.

**Дальше** игра обновляется сама: при запуске она проверяет новую версию, скачивает её и перезапускается.
Для игры по сети у всех должна быть одна версия — автообновление об этом и заботится.
